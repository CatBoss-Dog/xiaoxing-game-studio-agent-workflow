# Game Character Image Production

Preserve identity and same-use style before increasing output volume.

## Workflow

1. Read the formal character row, visual anchors, intended image use, and approved same-use references.
2. Extract the minimum non-negotiable identity cues and the emotional/gameplay purpose of the image.
3. Produce one sample or a small comparison set. Do not begin a batch before owner approval.
4. Compare rendering method, proportions, line treatment, material density, lighting, camera/view, canvas, margins, and background handling against same-use references.
5. Stop when style, identity, content safety, copyright provenance, or intended runtime use is uncertain.
6. Revise the selected candidate without changing protected identity anchors.
7. Name and archive using caller-supplied project rules. Never invent official names or overwrite a formal asset without authorization.
8. Mark candidate, approved source, and runtime-ready status separately.
9. Delete rejected duplicates and generation residue unless the project explicitly requires a labeled rejected-art archive.

## Completion Evidence

Report formal source, intended use, protected anchors, reference assets, candidate count, selected output, style comparison, dimensions/alpha status, formal/runtime status, archive path, and cleanup.
