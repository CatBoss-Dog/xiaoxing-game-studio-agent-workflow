# 使用与安装

## 不用 AI 也能用

从 README 的对应主题开始，复制模板到自己的交付目录。JSON 文件是字段和空白记录定义；制作 Excel 时按字段合同建表。需要公司固定版式时，另行提供有权使用的当前模板，不用本包替代它。

建议在自己的工作区建立：`inputs/` 保存获授权原件、`deliveries/<案名>/<日期_轮次>/` 保存输出、`knowledge/entries/` 保存调整。不要覆盖原稿，不把私人资料提交回这个公开仓库。

## 在 Codex 中用

把本包的 `.agents/skills/game-design-handoff/` **整个目录**复制到目标项目的 `.agents/skills/`，或自己的 `~/.agents/skills/`。保留内部 references 和 assets。不要只复制 SKILL.md，也不要覆盖已有同名定制 Skill。

打开目标项目的新会话，确认可用 Skill 中出现 `game-design-handoff`，再用 `$game-design-handoff` 调用。若尚未显示，可重启客户端核对；仅有磁盘文件不证明已加载。项目／用户级目录和发现机制参见 [官方 Skills 文档](https://learn.chatgpt.com/docs/build-skills)。

只有这个 Skill 是本包提供的能力。读取／渲染 DOCX、操作 Excel、图片生成、浏览器和音频工具由使用者的实际环境提供；缺少哪项就说明哪项，继续可独立完成的部分。不要把本包的路径当作可调用工具名称。

## 可以直接复制的请求

**从视频起案：**

> 使用 $game-design-handoff。基于我提供的视频和说明整理玩法策划案、配置结构、美术需求与音效需求。先给来源、已知事实、推断和待确认项；输出到我指定目录。缺少的产品决定不要编造。

**局部改稿：**

> 使用 $game-design-handoff。以这份当前稿为准，只改奖励界面的关闭和重进规则，同步受影响的图表，新增修改标黄。保留我的删改和其它章节；永久规范不要改。

**只要目录：**

> 使用 $game-design-handoff。按当前美术原表整理资源目录，逐项能找到详情，明确跨页复用和数量单位。未完成项不要标完成，不修改原表。

**整理调整供下次调用：**

> 使用 $game-design-handoff。汇总本次用户改动，保存来源、适用范围和待确认项。下次按请求读取对应资料；每次修改永久策划规则先给具体差异让我确认。

## 首次填写

打开 [项目信息模板](../.agents/skills/game-design-handoff/assets/templates/project-profile.json)，填当前项目、作者源、输出目录、人员和验收要求。项目路径、人物姓名、数值、工具账号均由使用者自己提供。没有信息就保持空值并记录缺口，不能从本包虚构案例推断项目设置。
