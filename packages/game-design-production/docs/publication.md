# 公开边界与来源

本包由既有游戏文档和资源交接经验重新编写为通用文字、字段合同与空白模板，遵循所在仓库的 MIT 许可。专用项目的身份、路径、人员、原始业务数据和数值未移植。

包含：策划流程、视频证据方法、Word 语义要求、配置结构、美术和音频字段、目录去重、UI 状态、修订记录、验收方法、可独立复制的 Skill 和虚构例子。

不包含：公司原案、公司专用 DOCX/XLSX、原始参考图／视频／音频、正式游戏源码或构建物、私人聊天和会话数据库、真实资料索引、账号凭据、第三方付费资源、厂商缓存 Skill 源码、插件运行时或自动化实例。

专用模板的文字作者、固定路径和项目名称在公开版中改成空白字段。这是供他人填写的公开模板，不会修改原使用者的永久规范，也不代表朋友的新项目已接受某套旧游戏规则。

首次分享采用本包列明的默认工作习惯；朋友可按自己项目的授权规范使用。拟把某条新经验变成其长期策划规则时，仍先走明确确认流程。

官方产品使用说明仅引用 [Skills 官方文档](https://learn.chatgpt.com/docs/build-skills) 的目录与加载方式，核对日期 2026-11-06。第三方工具实际能力以当次环境为准。

分享新版本时只打包明确白名单，重新检查 ZIP 里的文件、相对链接和内容；不要把 inputs、deliveries、knowledge 私人目录加入发布文件。哈希校验能发现意外变化，不能代替人工判断内容是否适合公开。
