# 验证说明

本包提供标准库脚本 `scripts/verify_package.py`。在包根目录运行：

```text
python scripts/verify_package.py
```

脚本核对 manifest 文件清单、SHA-256、大小、JSON 可读性、相对链接目标和链接是否越出包目录；检查 Skill 必要元信息及模板关键列数。结果会报告检查数量；失败时返回非零退出码。修改包内容后原清单将不再匹配，应复核内容后重新生成发布清单，而不是删除校验项掩盖变化。

发布时还应人工检查路由与边界：

| 场景 | 正确行为 |
|---|---|
| 只修改一段说明 | 保护当前稿，仅检查受影响内容及关联 |
| 修改配置字段 | 同步受影响的文档、表、引用与验收 |
| 整理美术或音效 | 保留相应表结构，不套三行配置表头 |
| 用户删去一条需求 | 记录当前状态，不从旧快照自动恢复 |
| 视频只展示部分动作 | 未观察到的机制列为推断或未知 |
| 给出一次案例调整 | 记录案例，不自动成为永久规则 |
| 提议修改永久规则 | 先给具体差异和影响，获得本次确认 |
| 只复制 Skill 目录 | 内部引用仍可解析，不依赖本机绝对路径 |
| 需要本机没有的制图工具 | 说明缺口，不能声称已出图 |
| 生成四张方案 | 总计四张；参考图、拼图不重复充数 |

本版本的发布检查包含：Skill 元信息、静态完整性、空白模板、公开内容扫描、ZIP 解压后的再校验。它们不证明已在朋友电脑安装成功，不代表已生成或验收游戏、正式 Word/Excel 或音频成品。每份实际交付仍执行 [验证流程](../.agents/skills/game-design-handoff/references/08-quality.md)。
