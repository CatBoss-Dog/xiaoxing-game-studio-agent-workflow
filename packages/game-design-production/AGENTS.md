# 本流程包的使用入口

这是独立的通用资料包，不是任何游戏项目的作者源。先读 [README](README.md)，再按当前请求读取 [game-design-handoff](.agents/skills/game-design-handoff/SKILL.md) 中对应专题。

当前用户指令及其项目已确认规范优先。没有项目授权时，只处理通用方法、用户提供的资料或明确标注的草案；不猜路径、不扫整盘、不绑定旧项目。

普通小改采用最小充分流程。只在明确授权且确有需要时分派代理；同一作者源维持单一写入席位。不要把上层仓库的旧版角色插件当成本包依赖。

保护用户当前稿、原件和历史。永久策划规则的新增、修改、删除或范围扩大，先展示原条款、拟改条款、理由、范围、影响并取得本次确认；记录案例不自动改变永久规则。

本包不带认证、不自动联网、不创建定时任务。外部发布、发送、安装和删除仍按实际任务授权执行。
