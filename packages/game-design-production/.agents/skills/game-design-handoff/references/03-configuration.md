# 配套配置表

[配置结构模板](../assets/templates/configuration-contract.json) 只用于程序配置工作簿。美术需求、资源目录、音效表分别按自己的结构，Word版式也不随Excel格式变化。

## 作者源

先确认程序实际读取的作者表、主键、字段、类型、枚举和引用关系。保留现有字段名称与分隔语法，配置值与运行时派生值分开。参数影响的规则须回链到策划案，未知数值留待确认；例子不能直接作为生产数据。

## 行结构与风格

- 第1行：中文说明，微软雅黑11号，浅蓝底 DEEBF7。
- 第2行：字段类型，10号，浅底 F0F5FB。
- 第3行：英文字段名，11号加粗、绿色 008D40。
- 第4行起：数据，11号，白／F3F7FB隔行，边框 DFE7EF。
- 主数据页冻结首行和首列，隐藏网格；不擅自增加合并大标题或自动筛选。
- Guide页用“项目／说明”结构，表头深蓝284D70白字，只冻结首行。

以上是本分享版的独立配置风格。有已批准作者模板时按其实际合同。文档修订标黄时保留必要类型／字段语义颜色。

Guide说明用途、各sheet、主键关系、字段格式、填表约束、边界、示例是否仅演示，以及未确认项。不能只有配色、没有数据合同。

## 检查

检查唯一ID、必填、类型、范围、外键与枚举；说明单位、精度、空值和默认行为。对有意义的公式检查计算与重算，不对纯静态表虚构公式验收。跨表引用和策划中的名称同步；导出或程序读取要求另行实测。

不要因表头正确就声称程序已经读取成功，表格预览正确也不等于配置机制已实现。
