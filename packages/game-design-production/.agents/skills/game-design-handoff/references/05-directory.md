# 美术资源目录与制作状态

目录帮助找详情与统计，不承担所有制作说明。使用 [目录合同](../assets/templates/directory-contract.json)；分sheet或分组按实际玩法模块，无固定页数与条数。

每条目录包含稳定需求编号、名称、类型、数量单位、新制／复用、归属模块、详情sheet／行或稳定定位、状态和待确认说明。目录链接须实际打开到正确页面或位置；只有文件名不能证明定位有效。

## 去重

先以确认后的资源ID判断复用，再人工核对名称、图和用途。没有ID时只标潜在重复，不能自动把同名异物合并。跨模块共享时记录主条目与引用条目，汇总只计主条目新制量，引用保留各自使用需求。

对账：目录有条目时能找到详情，详情的有效需求不会无故漏掉。数量单位、延期范围、资源分类和制作状态一致。删除／取消条目保留历史去向，不能重新从旧汇总加回去。

## 进度不是猜测

“已提出”“已确认”“制作中”“已提交”“已入端”“已验收”是不同证据层级。维护目录时按当前可核证据填状态，空排期留空；文件存在、生成图完成和程序截图不能分别冒充整个资源完成。

整理结束同时交付：目录、去重依据、原表问题清单、待确认范围。人工可读看板带更新时间，只是快照；没有后台监听时不声称实时同步。
