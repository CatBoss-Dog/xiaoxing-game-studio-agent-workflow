# 可复制模板

文件类型说明：Markdown是填写骨架；JSON是空白记录或表字段合同，未伪装成成品DOCX／XLSX。空数组与null表示尚未录入，不表示审核通过。JSON合同不是程序自动导入格式，实际项目需映射自身工具。

| 模板 | 用途 |
|---|---|
| [project-profile.json](project-profile.json) | 项目、范围、来源、交付及能力缺口 |
| [sources.json](sources.json) | 当前作者源／参考／历史定位 |
| [video-evidence.json](video-evidence.json) | 视频时间点与观察／推断／未知 |
| [design-document.md](design-document.md) | 策划案内容骨架 |
| [configuration-contract.json](configuration-contract.json) | 配置三行表头、Guide与字段约束 |
| [art-contract.json](art-contract.json) | 14列美术需求与数量语义 |
| [directory-contract.json](directory-contract.json) | 目录索引、去重和状态 |
| [audio-contract.json](audio-contract.json) | 13列音频需求 |
| [media-brief.md](media-brief.md) | UI／图片目的、状态和来源 |
| [change-record.json](change-record.json) | 当前稿变动及影响 |
| [permanent-rule-proposal.md](permanent-rule-proposal.md) | 逐次永久规则确认 |
| [knowledge-entry.json](knowledge-entry.json) | 用户调整与经验的范围化记录 |
| [requirement-index.json](requirement-index.json) | 四类按需调用入口 |
| [shared-state.json](shared-state.json) | 单会话自报及写入归属 |
| [acceptance.json](acceptance.json) | 实际验证与未决项 |
